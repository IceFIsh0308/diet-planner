🚀 详细部署流程

🍎 macOS
🪟 Windows
1
验证 Python 3
找到「终端」：按 Command(⌘) + 空格，输入「终端」，按回车打开。然后复制下面命令粘贴进去，按回车：
python3 --version
✅ 显示类似 Python 3.13.x → 说明已安装，直接进入第 2 步。
❌ 提示 command not found: python3 → 说明没装 Python。先安装：

xcode-select --install

弹出窗口点「安装」，等它跑完（可能要几分钟），完成后回到第 1 步重试。
❌ 装了还是找不到？→ 前往 python.org 下载 Python 3.13+ 安装包，双击安装（一路点继续），装完回到第 1 步重试。
2
安装 yt-dlp
yt-dlp 是视频解析的核心库。在同一个终端窗口粘贴执行：
python3 -m pip install yt-dlp
✅ 显示 Successfully installed yt-dlp-xxx → 进入第 3 步。
❌ 报错 externally-managed-environment → 改用下面这条再执行一次：

python3 -m pip install yt-dlp --break-system-packages

看到 Successfully installed → 进入第 3 步。
❌ 报 SSL: CERTIFICATE_VERIFY_FAILED（安装时下载失败）→ 先去完成第 3 步装证书，装完回到第 2 步重装。
❌ 提示 No module named pip → 先执行 python3 -m ensurepip --upgrade，然后回到第 2 步重试。
3
安装 SSL 证书（仅 Mac 需要，必须做）
Mac 的 Python 默认证书库是空的，不装这一步，下载时一定会报 SSL 错误。先确认 Python 版本目录：
ls /Applications | grep Python
看输出是 Python 3.13 还是别的，然后执行对应的证书脚本（以 3.13 为例）：
"/Applications/Python 3.13/Install Certificates.command"
✅ 最后一行显示 update complete → 进入第 4 步。此步只需做一次，以后不用再做。
❌ 提示 No such file or directory → 说明路径名不对。把第 3 步第一行命令的结果发给我，确认正确的版本目录名后再执行。
4
下载并解压工具包
点击页面上方绿色按钮「⬇️ 下载完整工具包」，得到 抖音视频解析.zip。
双击 zip 解压，得到「抖音视频解析」文件夹。把它移动到「下载」文件夹（位置自己记好，下一步要用）。
💡 如果你已经把文件夹放在别的位置，记住完整路径即可，下一步的命令相应修改。
5
启动服务
在终端输入下面命令（如果文件夹在别的位置，把 ~/Downloads/抖音视频解析 换成你的实际路径）：
cd ~/Downloads/抖音视频解析 && python3 server.py
✅ 看到 🌐 打开浏览器访问: http://127.0.0.1:8765/ → 进入第 6 步。终端窗口不要关闭，关了就停了。
❌ 提示 cd: no such file or directory → 路径不对。用下面命令先找到文件夹在哪，再重新进入第 5 步：

mdfind "kMDItemDisplayName == '*抖音*'"
❌ 提示 ❌ 未检测到 yt-dlp → 第 2 步没装成功，回到第 2 步重新安装。
❌ 报 Address already in use → 服务已经在运行了（可能之前开过），跳过启动，直接进入第 6 步，或者先按 Ctrl+C 停掉旧的再启动。
6
浏览器打开使用
打开你平时用的浏览器（Chrome / Safari / Edge），地址栏输入：
http://127.0.0.1:8765/
然后：① 抖音 App 打开视频 → 分享 → 复制链接 ② 粘贴到页面 ③ 选登录抖音的浏览器 ④ 点「解析并下载」
❌ 提示 cookie 读取失败 → 见下方常见问题 Q3，改用手动 Cookie 模式后回到本步重试。
❌ 报 SSL: CERTIFICATE_VERIFY_FAILED → 第 3 步没做或没成功，回到第 3 步装证书，再回来。
1
验证 Python 3
打开「命令提示符」：按 Win + R，输入 cmd，按回车。然后复制下面命令粘贴进去，按回车：
python --version
✅ 显示类似 Python 3.13.x → 说明已安装，直接进入第 2 步。
❌ 提示 不是内部或外部命令 → 说明没装 Python 或没加到 PATH：

① 前往 python.org 下载 Python 3.13+（Windows 安装包）
② 双击安装，务必勾选「Add Python to PATH」（界面最下方）
③ 安装完成后关掉 cmd 重新打开
④ 回到第 1 步重试
2

在同一个 cmd 窗口粘贴执行：
python -m pip install yt-dlp

Windows 不需要装 SSL 证书，Python 自带。
❌ 提示 不是内部或外部命令 → 说明 Python 没加到 PATH，回到第 1 步检查安装时是否勾选「Add Python to PATH」。
❌ 报 No module named pip → 先执行 python -m ensurepip --upgrade，然后回到第 2 步重试。
❌ 报 SSL 相关错误 → 多为网络/代理问题，稍后重试或切换网络后回到第 2 步。
3
下载并解压工具包
点击页面上方绿色按钮「⬇️ 下载完整工具包」，得到 抖音视频解析.zip。
右键 zip → 「全部解压缩」，得到「抖音视频解析」文件夹。推荐放到「下载」文件夹。
💡 记住你放的位置，下一步命令要用到。
4
启动服务
在 cmd 窗口输入下面命令（默认在「下载」文件夹，如位置不同请替换路径）：
cd %USERPROFILE%\Downloads\抖音视频解析 && python server.py
✅ 看到 🌐 打开浏览器访问: http://127.0.0.1:8765/ → 进入第 5 步。cmd 窗口不要关闭。
❌ 提示 系统找不到指定的路径 → 路径不对。打开「此电脑」找到「抖音视频解析」文件夹，右键 → 复制路径，然后回到第 4 步把路径替换进去。
❌ 提示 ❌ 未检测到 yt-dlp → 第 2 步没装成功，回到第 2 步。
❌ 报 Address already in use → 服务已在运行，直接进入第 5 步。
5
浏览器打开使用
打开浏览器（Chrome / Edge），地址栏输入：
http://127.0.0.1:8765/
然后：① 抖音 App 打开视频 → 分享 → 复制链接 ② 粘贴到页面 ③ 选登录抖音的浏览器 ④ 点「解析并下载」
❌ 提示 cookie 读取失败 → 见下方常见问题 Q3，改用手动 Cookie 模式后回到本步重试。

❓ 常见问题

Q1 · pip: command not found（找不到 pip）？
Mac：系统没有 pip 命令，用 python3 -m pip 代替（教程里已是这种写法，直接复制即可）。
Windows：多半是装 Python 时没勾「Add Python to PATH」。重装时务必勾选，装完关掉 cmd 重开。
解决后回到：Mac 第2步 / Windows 第2步
Q2 · 报 SSL: CERTIFICATE_VERIFY_FAILED（证书验证失败）？
仅 Mac 会出现。原因是 Mac 的 Python 证书库是空的。运行 macOS 详细流程第 3 步的证书脚本 Install Certificates.command，看到 update complete 即成功。
Windows 不会出现此错误，Python 自带证书。
解决后回到：Mac 第2步（重装 yt-dlp）或 第6步（如果只是下载报错）
Q3 · 提示 cookie 读取失败（读取浏览器登录态失败）？
自动读取浏览器登录态失败时，改用页面里的「手动 Cookie」模式：
① Chrome 安装插件 Get cookies.txt LOCALLY
② 打开抖音网页版并登录
③ 点插件 → Export → 复制内容
④ 粘贴到下载器页面「手动 Cookie」文本框 → 再点下载
解决后回到：Mac 第6步 / Windows 第5步（重新下载）
Q4 · 下载太慢 / 超时（180秒）？
多为网络波动或代理干扰。先重试一次；若仍超时，检查电脑是否开了代理/VPN（抖音直连更快），关掉代理再试。
特别慢的视频文件（几分钟的长视频）建议稍后再试，或避开晚高峰。
解决后回到：Mac 第6步 / Windows 第5步（重新下载）
Q5 · 提示「下载完成但未找到输出文件」？
视频实际下载到了 下载 文件夹但程序没认出来。直接打开 抖音视频解析/下载/ 目录查看最新文件，通常已在那。
也可能是下载失败只生成了临时文件，删除「下载」目录里的 0 字节/小文件后重试。
解决后回到：Mac 第6步 / Windows 第5步（重新下载）
Q6 · 下载提示「不支持此视频」或解析失败？
可能是视频是直播回放/付费内容/已删除，或链接过期。换一条能正常播放的抖音链接重试。
另外确认链接格式是 v.douyin.com/xxx 或 www.douyin.com/video/xxx，从 App 里「分享 → 复制链接」最保险。
解决后回到：Mac 第6步 / Windows 第5步（重新下载）
Q7 · 端口被占用（Address already in use）？
说明服务已经启动过（可能之前开过没关）。直接浏览器打开 http://127.0.0.1:8765/ 试试能不能用。
如果打不开，把之前所有终端窗口里的服务都按 Ctrl+C 停掉，重新执行启动命令。
解决后回到：Mac 第6步 / Windows 第5步
Q8 · 换电脑了怎么迁移？
文件夹即拷即用：把「抖音视频解析」文件夹整体拷到新电脑（U盘/网盘都行），已下载的视频也在里面。
环境要重装：新电脑需重新安装 Python 3、yt-dlp，Mac 还要再跑一次证书脚本（对应本页 macOS 第 1/2/3 步）。
更完整的迁移清单见工具包内「使用指南.docx」。
解决后回到：新电脑上从对应平台的第1步开始
工具仅在本机运行：Cookie 与视频数据不离开你的电脑。
